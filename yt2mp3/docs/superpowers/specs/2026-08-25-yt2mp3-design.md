# yt2mp3 — Design Spec

Date: 2026-08-25

## Purpose

A command-line tool that downloads a YouTube video or playlist and converts
it to MP3. Single-video and playlist URLs are both accepted; playlists
download each entry as a separate MP3.

## Interface

Installable Python CLI, entry point `yt2mp3`.

```
yt2mp3 <url> [-o OUTPUT_DIR] [-q QUALITY] [--filename-template TEMPLATE]
```

- `<url>` — a single video or playlist URL. yt-dlp detects which kind it is
  automatically; no separate flag needed.
- `-o, --output` — output directory. Default: `.`
- `-q, --quality` — MP3 bitrate in kbps. Default: `192`
- `--filename-template` — yt-dlp output filename template.
  Default: `%(title)s.%(ext)s`

## Dependencies

- Python 3.9+
- `yt-dlp` (Python package, used as a library — not shelled out to)
- `ffmpeg` must be present on the system `PATH`. yt-dlp uses it internally
  to extract and transcode audio to MP3. This is a system-level dependency
  the tool cannot install itself; it is checked for and reported clearly
  before any download starts.

## Architecture

Single package, no server, no persistent state. Each invocation is a
one-shot download-and-convert run.

```
yt2mp3/
├── pyproject.toml              # packaging + entry point (yt2mp3 = yt2mp3.cli:main)
├── src/yt2mp3/
│   ├── __init__.py
│   ├── cli.py                  # argparse setup, main()
│   ├── downloader.py           # wraps yt_dlp.YoutubeDL, builds config, runs download
│   └── checks.py               # verifies ffmpeg is on PATH
└── tests/
    └── test_downloader.py      # unit tests around config-building (no real network calls)
```

### Components

- **`cli.py`** — parses arguments, calls `checks.ensure_ffmpeg()`, then
  `downloader.download(...)`. Owns process exit codes.
- **`downloader.py`** — builds a `yt_dlp.YoutubeDL` options dict
  (`format: bestaudio/best`, postprocessor `FFmpegExtractAudio` with
  `preferredcodec: mp3`, `preferredquality: <quality>`, `outtmpl` from the
  filename template and output dir), registers a progress hook, and runs
  the download. Catches per-item `DownloadError` so one failing item in a
  playlist doesn't abort the rest.
- **`checks.py`** — `ensure_ffmpeg()` uses `shutil.which("ffmpeg")`; exits
  with an install-instruction message if not found.

## Data Flow

1. `main()` parses args.
2. `checks.ensure_ffmpeg()` — fail fast, before touching the network, if
   ffmpeg is missing.
3. `downloader.download(url, output_dir, quality, template)` constructs the
   `YoutubeDL` options and calls `.download([url])`.
4. yt-dlp handles video-vs-playlist detection internally; playlist entries
   download sequentially, each converted to its own MP3 by the
   `FFmpegExtractAudio` postprocessor.
5. A progress hook prints `Downloading: <title>` and `✓ Saved: <path>` per
   item to stdout.

## Error Handling

- **Missing ffmpeg** — immediate exit (before any download attempt) with a
  message pointing to install instructions for the user's likely platform.
- **Invalid/unreachable URL, age-restricted/private video** — yt-dlp raises
  `DownloadError`. Caught per playlist item: printed as a warning, download
  continues with the remaining items. Process exits non-zero at the end if
  any item failed.
- **Network errors** — same per-item catch-and-continue behavior as above.

## Testing

- Unit tests cover option-dict construction in `downloader.py` and the
  ffmpeg-presence check in `checks.py` (with `shutil.which` mocked).
- No tests hit real YouTube or the network — out of scope, since that would
  make CI flaky and dependent on an external, frequently-changing service.

## Out of Scope (for this version)

- GUI or web interface
- Resuming partial/interrupted downloads across separate invocations
- Non-MP3 output formats
- Concurrent/parallel downloads within a playlist
